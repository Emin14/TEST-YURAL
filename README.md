# Autoparts Catalog

React-приложение для двухэтапного поиска автозапчастей через Favorit Parts API.

## Быстрый старт

```bash
npm install
npm run dev
```

Проект запускается сразу: адрес API и демонстрационный ключ находятся в `src/shared/config/api.js`. При необходимости значения можно переопределить через `.env` на основе `.env.example`.

## Архитектура FSD

- `src/app` — точка входа и подключение Redux;
- `src/pages` — страница каталога;
- `src/widgets` — крупные блоки интерфейса поиска и результатов;
- `src/entities/catalog` — Redux-модель каталога и use cases поиска;
- `src/shared` — API-клиент, конфигурация, форматтеры и общие UI-компоненты.

Код форматирован многострочно для удобства ревью. Ошибки API переводятся на русский, включая превышение лимита запросов (`Request quota exceeded!`).
